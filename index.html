Demonstrated CRUD Operations

1. insertOne()
Insert Operation

Inserts a single document representing an inventory item into the collection.

db.items.insertOne({
  name: "Wireless Mouse",
  category: "Electronics",
  price: 25.99,
  quantity: 150,
  inStock: true,
  tags: ["accessories", "wireless", "computer"]
})
2. insertMany()
Insert Operation

Inserts multiple diverse inventory products in a single batch operation.

db.items.insertMany([
  { name: "Mechanical Keyboard", category: "Electronics", price: 89.99, quantity: 75, inStock: true, tags: ["gaming", "rgb"] },
  { name: "Gaming Monitor 27-inch", category: "Electronics", price: 299.99, quantity: 30, inStock: true, tags: ["display", "144hz"] },
  { name: "USB-C Hub Multiport", category: "Electronics", price: 34.50, quantity: 120, inStock: true, tags: ["adapter", "usb-c"] },
  { name: "Noise-Cancelling Headphones", category: "Audio", price: 149.99, quantity: 45, inStock: true, tags: ["audio", "bluetooth"] },
  { name: "Desk Mat Extended", category: "Office Supplies", price: 19.99, quantity: 200, inStock: true, tags: ["desk", "pad"] }
])
3. find()
Read Operation

Retrieves all documents matching filter criteria: category: "Electronics" and inStock: true.

db.items.find({ category: "Electronics", inStock: true })
4. findOne()
Read Operation

Retrieves exactly one document matching the query condition where name is "Mechanical Keyboard".

db.items.findOne({ name: "Mechanical Keyboard" })
5. updateOne()
Update Operation

Modifies price, quantity, and updates timestamp for "Wireless Mouse" using $set and $currentDate.

db.items.updateOne(
  { name: "Wireless Mouse" },
  { $set: { price: 22.99, quantity: 140 }, $currentDate: { lastModified: true } }
)
6. updateMany()
Update Operation

Updates all Electronics items with onSale: true and increments stock by 10 using $inc.

db.items.updateMany(
  { category: "Electronics" },
  { $set: { onSale: true }, $inc: { quantity: 10 } }
)
7. deleteOne()
Delete Operation

Deletes "Desk Mat Extended" from collection. Confirmed via follow-up find() query returning 0 items.

db.items.deleteOne({ name: "Desk Mat Extended" })
8. deleteMany()
Delete Operation

Deletes all items matching category: "Audio". Confirmed via follow-up find() returning 0 items.

db.items.deleteMany({ category: "Audio" })
